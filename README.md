## Download

**[⬇️ Download the latest build](https://github.com/Mark-snow/trace-releases/releases/latest)**

Grab the `.apk` file from the latest release, or browse
[all builds](https://github.com/Mark-snow/trace-releases/releases) to pick a specific one.

## Installing on Android

Because Trace is distributed outside the Google Play Store, Android will ask
for permission before installing:

1. Download the `.apk` file to your Android device.
2. Open it (from your browser's downloads or a file manager).
3. If prompted, allow **"Install unknown apps"** for that app — Android shows
   a settings screen where you can enable it, then go back and continue.
4. Tap **Install**.

You only need to allow this once per source (e.g. your browser).

## Requirements

- Android [X.0] or newer
- Roughly [XX] MB of free space

## Updates

Each build is published as a separate release, tagged `build-1`, `build-2`, and
so on. To update, download the newest `.apk` and install it over your existing
version — your data is preserved as long as it's the same app.
