# Trace

Trace is a free, fully offline Android app for splitting bills fairly with friends, family, or roommates — evenly, by percentage, by shares, or item by item.

This repository hosts **downloadable builds only**. The app's source code is developed in a private repository.

## Download

Get the latest APK from the **[Latest release](https://github.com/Mark-snow/trace-releases/releases/latest)** page. Download the `.apk` file from the "Assets" section and open it on your Android device to install.

## Installing on Android

Since Trace isn't distributed through the Google Play Store, Android will ask for permission before installing it — this is normal for any app downloaded outside the Play Store.

1. Download the `.apk` file from the [latest release](https://github.com/Mark-snow/trace-releases/releases/latest) using your phone's browser.
2. When you open the downloaded file, Android may block the install and show a message like **"For your security, your phone is not allowed to install unknown apps from this source."**
3. Tap **Settings** on that prompt (or go to **Settings → Apps → Special app access → Install unknown apps**), select the app you downloaded with (e.g. Chrome, Files), and turn on **Allow from this source**.
4. Go back and open the `.apk` file again, then tap **Install**.

You only need to do this once per app you use to download the APK. This permission doesn't give any app extra access beyond letting it install files you choose.

## Requirements

- Android 8.0 (Oreo) or newer

## Updates

There's no auto-update or Play Store listing — new versions are published here as GitHub Releases. Each build is tagged `build-<number>` (e.g. `build-12`), so every release corresponds to a specific build. Check the **[All releases](https://github.com/Mark-snow/trace-releases/releases)** page for the changelog and to grab a specific past version, or just use the **[Latest release](https://github.com/Mark-snow/trace-releases/releases/latest)** link to always get the newest build.

## Privacy

Trace works entirely offline. It doesn't require an account, doesn't collect any data, and never sends anything over the network — everything you enter stays on your device for the life of that session.
